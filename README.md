# Сайт-приглашение · Вилла Романов · 12.09.2026

Промежуточная версия на основе макета **Dolce Vita** (без итальянской тематики): бело-зелёно-розовая палитра, пионовидные розы, все блоки из брифа.

## Запуск локально

```bash
cd wedding-invite-villa-romanov
npm start
```

Откройте: http://localhost:3847  
Анкеты гостей (для молодожёнов): http://localhost:3847/admin  
Пароль по умолчанию: `svadba2026` (смените: `set ADMIN_PASSWORD=ваш_пароль` перед `npm start`).

## Что нужно дополнить перед финалом

1. **Имена** — в `public/js/config.js` → `names: ["...", "..."]`
2. **Telegram** — `telegramUrl: "https://t.me/..."`
3. **Музыка** — файл `public/audio/na-beregu-neba-instrumental.mp3` (минусовка)
4. При необходимости — заменить заглушку «Имя и Имя» на обложке

## Анкета и база

Каждая отправка формы сохраняется **без внешних зависимостей** в файл:

- `data/guest_responses.jsonl` (формат JSON Lines: одна строка = один гость)

В админке: просмотр таблицы и выгрузка CSV.

## Отправить друзьям (публичная ссылка)

**`localhost` у друзей не откроется.** Подробно: **[DEPLOY-RU.md](./DEPLOY-RU.md)**

- **Быстро:** `share-online.bat` → скопировать ссылку `https://....trycloudflare.com`
- **Навсегда:** бесплатно на [Render.com](./DEPLOY-RU.md) (инструкция в файле)
